# 桌面图标跳舞 · Windows 版

让 Windows 桌面上的图标自己动起来：拼成一个小人运球，或者排成一条会扭的长队，跟着电脑正在播放的音乐跳。

- **不动你的文件**。它只是在桌面上方画图标的副本，从不移动、改名、删除任何东西；退出、崩溃、被强制结束后桌面都是原样。
- **不用选歌**。电脑上放着什么（网易云、抖音、浏览器…）它就跟着什么跳。不用麦克风，系统也不会弹权限框。
- **桌面是空的也能玩**。图标不够时借「已安装的应用」的图标来凑数，只借来显示，不会往桌面放任何文件。
- 一个 exe，不用安装，不要管理员权限。

> **目前的状态（请先看这一段）**
> Windows 版已在作者自己的 Windows 10 笔记本上实测过（桌面 55 个图标）。**Windows 11 还没试过。**
> 还没核对过的情况写在下面的「已知限制」和「还没验证的」里。遇到任何不对劲，按 `Esc` 就能回到原样的桌面。

## 下载

需要 64 位的 Windows 10（1809 或更新）或 Windows 11。

1. 点这里直接下载：[DesktopDance-win.exe](../../../releases/latest/download/DesktopDance-win.exe)
   （或者到本仓库的 [Releases](../../../releases/latest) 页面找 `DesktopDance-win.exe`）。
2. 文件大约 60～80 MB——里面自带了运行库，所以**不用**另外安装 .NET 之类的东西。放在哪个文件夹都行。

## 第一次打开

1. 双击 `DesktopDance-win.exe`。
2. Windows 会弹一个大窗口「Windows 已保护你的电脑」。这是因为这个程序没有花钱买微软的签名，不是因为它有问题。
   点 **「更多信息」**，再点下面出现的 **「仍要运行」**。只有第一次需要这样。
3. 第一次启动要等几秒（它在解开自带的运行库）。之后屏幕左下角会出现一个小控制窗口。
4. 点 **「开始蹦迪」**。

个别杀毒软件可能会对没有签名的新程序报警。不放心的话可以自己从源码构建，见最下面。

## 怎么用

| 控件 | 作用 |
| --- | --- |
| 开始蹦迪 / 暂停 / 恢复桌面 | 开始、暂停、图标飞回原位并撤掉舞台 |
| 模式 | 打篮球（默认）、列队、律动、自由；勾「自动切换」会轮流播 |
| 舞台 | 全屏，或居中的 9:16 竖屏（带取景框四个角，录屏时对着框选） |
| 篮球 | 「打篮球」里用哪个图标当球。默认是第一个图标 |
| 跟着电脑正在播放的音乐跳 | 默认勾上。不勾或没声音时按内置的 120 拍跳 |
| 速度 / 幅度 / 数量 | 舞步快慢、摆动大小、图标总数（跳舞中拖完松手，过一两秒图标会按新数量重新排一次）。打篮球里「幅度」是动作夸张程度：默认位置是原样，越大手脚挥得越开（为了不出画，小人会相应缩小一些） |
| 图标名称 | 图标下面带不带名字。录视频建议关掉，小人轮廓更干净 |
| 截屏 / 录屏时隐藏本窗口 | 全屏录制时勾上，控制窗口就不会入镜（需要 Windows 10 2004 或更新） |
| 语言 | 控制窗口上的字用中文还是 English。第一次打开时跟系统走（系统是中文就用中文，否则英文）；在这里改了以后会记住。切换立刻生效，不用重开，跳舞中切换也不会打断 |

**随时恢复：按 `Esc`**。也可以点「恢复桌面」、在桌面上随便点一下、或者直接关掉控制窗口。

桌面上的真实图标（文件、文件夹、快捷方式、「此电脑」「回收站」都算）都可以上场。「数量」是多少，就有多少个图标跳舞：桌面图标比「数量」多时，多出来的留在原位不动；不够时借已安装应用的图标补位。暂停时改的数量，会在点「继续」后生效。

## 它怎么保证桌面不出事

程序**从不移动、隐藏、改名或删除任何真实图标，也不改资源管理器或系统的任何设置**。它做的只有一件事：
开一个属于自己的窗口，铺满主显示器，垫在所有其他窗口的最底下（只比桌面高一层），在里面画图标的副本。

- 窗口里先铺一张和你的壁纸一样的图，把真实图标盖住，再画副本，看起来就是图标自己在跳。
- 这个窗口只活在本程序里。正常退出、程序出错、在任务管理器里「结束任务」、断电重启——只要程序没了，窗口就没了，真实桌面原样露出来。
  没有任何需要「恢复」的东西留在系统里，所以也从来不需要重启资源管理器。
- 跳舞期间真实图标被盖在下面点不到（免得隔着遮罩误拖），在桌面上点一下就停止。
- `Esc` 不依赖程序界面：万一界面卡死，按下后 3 秒内没恢复，程序会直接结束自己，舞台跟着消失。
- 结束后它会再读一遍每个图标的位置和开始前比一比，结果记在日志里；万一发现有图标的位置变了，会在控制窗口里提醒（只读，不会去「纠正」任何东西）。
- 读图标位置、名字、壁纸用的都是系统的只读接口；不往别的程序里写内存，不联网。

## 已知限制

- **遮罩是照着壁纸设置自己铺的一张图**，不是截屏。普通的图片壁纸（填充、适应、拉伸、平铺、居中、跨区）会照样铺；
  但下面这些情况，开始和结束的一瞬间能看出背景变了一下：动态壁纸软件（Wallpaper Engine 之类）、幻灯片壁纸刚好在换图、
  每台显示器各设了不同的壁纸。只影响观感，不影响桌面安全。
- **多显示器**：只在主显示器上跳；其他显示器上的桌面图标保持原样，不参加。
- **按 `Win+D`（显示桌面）** 时系统会把真正的桌面提到最前面，舞台会被挡住；再按一次或点开任意窗口就回来。
- 跳舞期间 `Esc` 被全局占用（为了随时能恢复），其他程序暂时收不到 `Esc`；停下来就还回去。
- 副本上不画快捷方式左下角的小箭头。
- 「打篮球」跟音乐的方式是**快慢**：歌快动作就快，歌慢动作就慢（100 拍为原速，0.75–1.4 倍之间平滑变化），不会在每个鼓点上抖一下。它不保证每次拍球正好踩在鼓点上。列队、律动、自由三个模式是逐拍跟的。
- 中途换了输出设备（插拔耳机、切到蓝牙音箱），大约 3 秒后会自动重新跟上声音。
- 改了分辨率或缩放比例时，程序会自动停下并恢复桌面，需要重新点「开始蹦迪」。

## 还没验证的

Windows 版目前只在作者的一台 Windows 10 笔记本上跑过。下面这些**还没有逐项核对过**，可能有出入：

- 副本一开始和真实图标是不是严丝合缝地重合（位置、大小差几个像素都有可能）
- 遮罩和真实壁纸是不是完全对得上
- 舞台窗口在各种情况下是不是都老老实实待在最底下（Windows 10 和 11 各版本、开着全屏游戏或视频时）
- 150%、200% 等缩放比例，以及 4K 屏上的流畅度
- 商店应用（计算器、照片…）的图标借来显示时好不好看
- 英文界面（English）：是后加的，字有没有被截掉、切换是否顺畅，还没在真机上看过
- Windows 11（一次都还没跑过）

测试步骤见 [TESTING.md](TESTING.md)。

## 出问题时

按 `Esc`。如果想告诉作者哪里不对，请带上日志文件：

1. 按 `Win+R`，粘贴 `%LocalAppData%\DesktopDance` 回车。
2. 里面的 `desktop-dance.log` 就是日志（只记录程序自己做了什么，不含你的文件内容；会包含桌面图标的名字）。

同一个文件夹里的 `settings.json` 记着上次选的篮球、两个勾选项和界面语言，删掉就恢复默认。日志始终是中文，不随界面语言变。

## 打篮球的动作从哪来

和 Mac 版用的是同一份数据：[motion/basketball-motion.json](../motion/basketball-motion.json)。
它是从一段全身入镜的运球视频里逐帧取出的 17 个关节的位置（动作捕捉），文件里**只有关节坐标**，不含任何视频画面。
想换动作的话，用 Mac 版提取出新的 json，放到 `%LocalAppData%\DesktopDance\basketball-motion.json` 即可，不用重新构建。

## 从源码构建

不想用现成的 exe，可以自己构建。需要一台 Windows 电脑和 [.NET 8 SDK](https://dotnet.microsoft.com/download/dotnet/8.0)：

```bash
dotnet publish windows/DesktopDance.csproj -c Release -r win-x64 --self-contained true -p:PublishSingleFile=true -p:IncludeNativeLibrariesForSelfExtract=true -p:EnableCompressionInSingleFile=true -o publish
```

生成的 `publish\DesktopDance.exe` 就是成品。仓库里的 [GitHub Actions 流程](../.github/workflows/windows-build.yml) 做的是同一件事。

代码怎么分的：

| 文件 | 内容 |
| --- | --- |
| [src/Choreo.cs](src/Choreo.cs) | 四种队形和舞步，每个模式一个函数（想改动作改这里） |
| [src/MotionClip.cs](src/MotionClip.cs) | 读动作数据、补洞、平滑、循环 |
| [src/Audio.cs](src/Audio.cs) | 鼓点检测、节拍时钟、听系统声音 |
| [src/Desktop.cs](src/Desktop.cs) | 读桌面图标的位置 / 名字 / 图片，借应用图标，铺壁纸遮罩 |
| [src/Stage.cs](src/Stage.cs) | 舞台窗口和画面 |
| [src/Controller.cs](src/Controller.cs) | 开始 / 暂停 / 恢复的总控 |
| [src/Panel.cs](src/Panel.cs) | 控制窗口 |
| [src/HotKeys.cs](src/HotKeys.cs) | `Esc` 热键 |
| [src/SelfTest.cs](src/SelfTest.cs) | 自检（`DesktopDance.exe --selftest 输出文件夹`） |
