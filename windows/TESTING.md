# Windows 版测试清单

这份是给愿意在自己的 Windows 电脑上帮忙测试的人看的。Windows 版目前只在作者的一台 Windows 10 笔记本上跑过，Windows 11 还没有人试过。
照着编号往下做，每一步写了「应该看到什么」。
哪一步不对，记下编号，最后按第 9 步把东西发回来。

**放心试：程序不会动桌面上的任何东西。任何时候觉得不对，按 `Esc`；再不行就在任务管理器里结束 `DesktopDance-win.exe`，桌面会原样回来。**

## 0. 拿到 exe

两种拿法：

- **一般情况**：点仓库首页 [README](../README.zh-CN.md) 里的「下载 Windows 版」按钮，得到 `DesktopDance-win.exe`。
  每次代码更新、GitHub 自动构建并自检通过后，按钮给出的 exe 会自动换成最新的。
- **想测某一次构建**：打开仓库页面 → 上方 **Actions** → 左边选「Windows 版构建」→ 点你要的那一次（要是绿色的勾）→
  拉到页面最底下 **Artifacts** → 点 `DesktopDance-win` 下载，得到一个 zip，解压出 `DesktopDance-win.exe`。（要登录 GitHub 才能下，只保留 7 天。）

如果那一次构建是红色的叉：不用测了，把那个页面的网址发回来就行。

## 1. 第一次打开

1. 双击 `DesktopDance-win.exe`。
2. 弹出「Windows 已保护你的电脑」→ 点「更多信息」→ 点「仍要运行」。
3. 等几秒。

应该看到：屏幕左下角出现一个小窗口，标题「DesktopDance」。最下面一行灰字写着「就绪 · 桌面上有 N 个图标」。

- [ ] 窗口出来了，中文没有乱码
- [ ] N 和桌面上实际的图标数一样（「此电脑」「回收站」也算）
- [ ] 「篮球」下拉菜单里能看到桌面图标的名字

## 2. 开始

先不放音乐。点「开始蹦迪」。

应该看到：等 1～3 秒，然后桌面图标飞起来，在屏幕中间拼成一个运球的小人，其中一个图标当球。

- [ ] **壁纸**：开始那一瞬间背景有没有变（变暗、变色、错位、被拉伸）？应该几乎看不出变化
- [ ] **图标起点**：图标是不是从它们原来的位置飞出去的？起飞前有没有先「跳」一下（位置偏几个像素、大小突然变了）？
- [ ] 桌面上原来的图标看不见了（被盖住了），只有会动的副本
- [ ] 小人在动：运球、换手、举球……动作连贯，大约 17 秒循环一次
- [ ] 任务栏还在原来的位置，没有被盖住
- [ ] 其他打开的窗口（浏览器之类）还在舞台上面，能正常用
- [ ] 控制窗口里写着「跳舞中」，后面的 fps 数字接近显示器刷新率（60 左右或更高）。**记下这个数字**
- [ ] 画面流畅，不卡

## 3. 跟音乐

把模式切到「律动」（这个模式是逐拍跟的，最容易看出来）。用任何软件放一首节奏明显的歌（网易云、浏览器都行），就用平时听歌的方式。

应该看到：几秒内控制窗口的状态变成「跟随系统声音 · xxx BPM」，图标在每个鼓点上压一下、弹一下。

- [ ] 整个过程**没有**弹出任何权限询问
- [ ] 状态里出现「跟随系统声音」，BPM 数字大致是这首歌的速度
- [ ] 「律动」里图标的弹跳和鼓点对得上
- [ ] 把歌暂停：几秒后出现「现在没听到声音，先按内置节拍跳」，图标继续按固定节奏跳
- [ ] 再播放：又跟上了
- [ ] 模式切回「打篮球」，继续放歌：小人**不会**在鼓点上一抖一抖（图标大小不变、不歪、不弹），动作是连贯的；
      歌明显比 100 拍快或慢时，状态里会多一行「跟着音乐：动作速度 x.xx 倍」，动作整体变快或变慢
- [ ] 取消勾选「跟着电脑正在播放的音乐跳」：变成「内置节拍 · 120 BPM」，打篮球回到原速

## 4. 各个控件

跳舞过程中逐个试：

- [ ] 模式切到「列队」：图标排成一列，然后拉长、弯成 S 形
- [ ] 模式切到「律动」：图标回到各自原位，原地一压一弹
- [ ] 模式切到「自由」：图标聚到中间转圈，鼓点时向外弹开
- [ ] 勾「自动切换」：过一阵会自己换模式
- [ ] 舞台选「9:16 竖屏」：队形收进屏幕中间一个竖条里，四个角有白色取景框；取消「取景框」角标消失
- [ ] 取消「图标名称」：图标下面的名字消失
- [ ] 拖「速度」「幅度」：马上有变化。打篮球里「幅度」往右拖，手脚挥得更开、蹲得更低，小人略微变小但不出画；往左拖动作收着
- [ ] 「篮球」换一个图标：打篮球模式里球换成它
- [ ] 跳舞中把「数量」往小拖然后松手：过一两秒，只剩这么多个图标在跳，其余的桌面图标留在原位不动
- [ ] 跳舞中把「数量」往大拖（比桌面图标数还多）然后松手：过一两秒，所有桌面图标都上场，还多出借来的应用图标
- [ ] 暂停时拖「数量」：画面不动；点「继续」后才按新数量重排
- [ ] 点「暂停」画面定住，按钮变成「继续」，点了继续跳
- [ ] 跳舞中把最下面的「语言」换成 English：窗口上所有的字（按钮、模式名、勾选项、状态那几行）立刻变成英文，
      没有哪个字被截掉一半，图标照常在跳、没有停顿；换回「中文」同样
- [ ] 语言选了 English 后关掉程序再打开：还是英文（记住了）

## 5. 恢复（最重要）

下面每一种都试一次（每次试完重新点「开始蹦迪」）：

- [ ] 按 `Esc`：舞台立刻消失
- [ ] 点「恢复桌面」：图标飞回原位，然后舞台消失
- [ ] 在桌面空白处点一下：同上
- [ ] 直接关掉控制窗口（点右上角 ×）：舞台消失，程序退出

每次恢复后检查：

- [ ] 桌面图标全都在，位置和开始前一模一样，没有多出或少掉任何文件
- [ ] 控制窗口最下面只剩一行「就绪 · 桌面上有 N 个图标」（如果多出一行「注意：有 N 个桌面图标的位置和开始前不一样」，记下来）
- [ ] 壁纸、任务栏正常，`Esc` 在别的程序里又能用了

## 6. 强制结束

1. 点「开始蹦迪」。
2. 按 `Ctrl+Shift+Esc` 打开任务管理器，找到 `DesktopDance-win.exe`（或 `DesktopDance`），右键 →「结束任务」。

- [ ] 舞台立刻消失，桌面图标都在原位
- [ ] 不需要重启资源管理器、不需要重启电脑
- [ ] 再次双击 exe 能正常打开

## 7. 桌面图标很少 / 很多

- [ ] 把「数量」拖到 96 再开始：不够的部分用应用图标补上，补位的图标好不好看（有没有白色方块、糊的、空白的）
- [ ] 把「数量」拖到 12 再开始：只有 12 个图标跳舞，其余的桌面图标留在原位不动，没有补位

## 8. 有条件再试（没有就跳过）

- [ ] 换一个缩放比例（设置 → 显示 → 缩放，比如 150%）后再开始，看第 2 步的壁纸和图标起点
- [ ] 跳舞时按 `Win+D`：会看到真实桌面，再按一次回到舞台
- [ ] 跳舞时插拔耳机：几秒后还能跟上音乐
- [ ] 第二台显示器：只在主显示器上跳，另一台上的图标不动
- [ ] 勾「截屏 / 录屏时隐藏本窗口」后截一张全屏图（`Win+Shift+S` 或 `PrtSc`）：图里没有控制窗口

## 9. 发回来什么

不管成不成功，都请发：

1. **日志文件**：按 `Win+R`，粘贴 `%LocalAppData%\DesktopDance` 回车，把里面的 `desktop-dance.log` 发回来。
2. **Windows 版本**：按 `Win+R` 输入 `winver` 回车，把那几行字抄下来或截图。
3. **缩放比例和分辨率**：设置 → 系统 → 显示 里的「缩放」和「显示器分辨率」。
4. 第 2 步记下的 **fps 数字**。
5. 哪几步的编号没通过，各一句话说看到了什么。能截图或录一小段屏最好——
   尤其是第 2 步「开始前」和「开始后一秒」各一张全屏截图，用来比对壁纸和图标位置。

如果程序根本打不开（双击没反应，或弹出报错窗口）：把报错窗口截图，并看一下 `%LocalAppData%\DesktopDance` 里有没有日志文件，有就发回来。
